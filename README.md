# AI Agent Maker のリリース

AI Agent Maker のインストーラと、更新の情報を置く場所です。ソースコードはここにはありません。

- 最新版のダウンロードは [Releases](../../releases/latest) から
- macOS: `AI-Agent-Maker-<版>-arm64.dmg`（Apple シリコン）、`AI-Agent-Maker-<版>-x64.dmg`（Intel）
- Windows 11: `AI-Agent-Maker-Setup-<版>.exe`

アプリは、組織が許可したときだけ、ここに新しい版があるかを確かめます。送るのはアプリの版と OS だけです。
